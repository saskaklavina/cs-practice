\#состояния локально гита

\##рабочая папка

рабочая папка содержит файлы проекта, которые я сейчас изменяю

\##индекс

индекс содержит изменения, выбранные командой git add для след коммита

\##коммит

коммит - сохраненный снимок подготовленных изменений

\## различия git и GitHub

&#x20;git - программа для ведения истории проекта на компьютере.

она позволяет создавать коммиты, ветки и объединять изменения

&#x20;GitHub - интернет сервис для хранения гит репозиториев, совместной работы и проверки кода

\# использованные команды

git status - показывает состояние рабочей папки и индекса

git diff - показывает изменения, еще не добавленные в индекс

git diff --staged - показывает изменения след коммита
